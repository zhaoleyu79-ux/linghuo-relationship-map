五种场景

场景 1

撮合/中介：平台只做媒，不做当事人

民事中介 · 非劳动关系
依据：《民法典》第919、961、963条（委托/中介合同）；《人力资源服务机构管理规定》（人社部令第50号）第5、9条；《新就业形态办法（征求意见稿）》第53条；国务院令第810号、税总2025年第15号公告；《个人所得税法》第9条。
法律定性民事中介；非劳动关系
谁签合同客户 ↔ 零工；平台只签信息服务协议
谁付款客户 → 零工；客户 → 平台服务费
谁扣个税客户（支付方）
谁缴社保无雇主社保；零工可灵活就业自愿参保
发票平台开服务费发票；零工开票/平台代办
资质职业中介→人力资源服务许可证；信息发布→备案
主要风险平台控制过深→转包/派遣；第53条；二清；未扣缴
平台越像“撮合”，越不能碰钱、碰人、碰考核——否则会被穿透为转包或派遣。
场景 2

转包/承揽：平台是承包方，但不一定是雇主

民事承揽/外包 · 平台是合同当事人
依据：《民法典》第770、772、779、787条（承揽合同）；《劳动合同法》第94条；《劳务派遣暂行规定》第27条；《新就业形态办法（征求意见稿）》第31、36条；财税〔2016〕47号第三条；《发票管理办法》。
法律定性民事承揽/外包；平台可能是雇主或支付方
谁签合同客户 ↔ 平台（外包/承揽）；平台 ↔ 零工
谁付款客户 → 平台（全额）；平台 → 零工
谁扣个税平台（支付方/雇主）
谁缴社保平台（若雇人）；个体承揽无雇主社保但有穿透风险
发票平台开全额服务发票；平台取得零工发票/代办
资质看业务；若实为派遣→派遣许可证
主要风险假外包真派遣（27条）；94条连带；社保穿透；虚开
平台是承包方，不等于平台是雇主；但一旦雇人，社保和劳动法义务就来了。
场景 3

劳务派遣：平台是派遣单位，客户是用工单位

劳动关系 · 平台是雇主
依据：《劳动合同法》第57–67、92条；《劳务派遣暂行规定》第3、4、5、27条；《劳务派遣行政许可实施办法》（人社部令第19号）；财税〔2016〕47号第一条；《社会保险法》第10、23、58条。
法律定性劳动关系（派遣）
谁签合同派遣单位 ↔ 零工（劳动合同）；派遣单位 ↔ 客户（派遣协议）
谁付款客户 → 派遣单位；派遣单位 → 零工
谁扣个税派遣单位（工资薪金）
谁缴社保派遣单位
发票派遣服务发票（差额5%部分不得开专票）
资质劳务派遣经营许可证
主要风险10%比例、三性、连带责任、许可
派遣是最重的模型：平台是雇主，客户是用工单位，两头都跑不掉。
场景 4

平台用工（目标）：平台不是雇主，客户不是雇主

非劳动关系 · 第三类平台用工
依据：《新就业形态办法（征求意见稿）》第3、31、33、34、36、41、42、53条；《民法典》第770、772、779条；《个人所得税法》第9条；税总2025年第16号公告、第15号公告；国务院令第810号；《社会保险法》第10、23、58条；人社部发〔2025〕24号；《人力资源服务机构管理规定》第5、9条。
法律定性非劳动关系的平台用工（第三类）
谁签合同平台 ↔ 零工（书面用工协议）；客户 ↔ 平台（合作协议）
谁付款客户 → 平台（服务费）；平台 → 零工（任务包报酬）
谁扣个税平台（劳务报酬；16号公告）
谁缴社保无雇主社保；职业伤害保障；零工可灵活就业自愿参保
发票平台开平台服务发票；平台按16号公告代办/零工开票
资质人力资源服务许可/备案；网络招聘→电信许可
主要风险客户管人→共同管理/派遣；平台支配→劳动关系；第36条；22号公告
平台不是雇主，但平台是书面用工协议的一方；平台义务不是雇主义务，但不能省。
场景 5

共同管理（风险变体）：三方协议不是免责协议

三方书面用工协议 · 共同责任
依据：《新就业形态办法（征求意见稿）》第31条第3款、第34、36、41、42条；《民法典》第770、772、779条；《劳动合同法》第94条；法释〔2025〕12号第3条；《劳务派遣暂行规定》第27条。
法律定性非劳动关系，但共同管理
谁签合同平台 + 客户 + 零工（三方书面用工协议）
谁付款客户 → 平台；平台 → 零工
谁扣个税平台（劳务报酬）
谁缴社保无雇主社保；职业伤害保障
发票平台开服务发票
资质平台 + 合作企业资质审核（第34条）
主要风险共同被告（第41条）；连带；第34条监督责任；第36条穿透
三方协议不是“三方免责”；它是共同管理的自认，能用两方协议就不要用三方。

五句话记住

  1. 撮合：平台不签合同、不碰钱、不管人，只收佣金；但推送、结算、评价可能触发第53条。
  2. 转包：平台是承包方，收全额、开全额票；可能是雇主，也可能只是支付方；客户管人就变派遣。
  3. 派遣：平台是雇主，要许可证、三性、10%；最重，不适合“平台不是雇主”的定位。
  4. 平台用工（目标）：平台签书面用工协议，但不是劳动合同；平台不是雇主，但承担平台义务；客户不管人。
  5. 共同管理：三方协议不是免责协议；共同管理＝共同被告/连带风险；能用两方协议就不要用三方。
